# First Class Trucking browser automation

This workspace moves the client engagement through intake, workflow specification, browser discovery, Playwright implementation, independent QA, delivery, and maintenance.

Open this directory as the Codex project, then start with:

```text
Use $run-client-playwright-pod to onboard First Class Trucking from the materials in intake/source-material.
```

Add SOPs, redacted notes, and process references to `intake/source-material/`. Do not place passwords, tokens, cookies, storage state, MFA recovery codes, or raw sensitive exports in this workspace.

The current stage and approval gates are in `project-state.json`. A stage is not complete because an agent says so; its required artifacts must exist and pass validation.
